Edit or cancel an order that isn't collected yet

Today the only fix is Cancel in the cash counter's Recent strip: last 5 orders from the same till, and only while the order is New. Once the food counter taps Start, a mistake can't be corrected and the report keeps the wrong sale. This proposal adds an Open orders list on every till where the cash counter edits or cancels, with a payment prompt so the cash box and card machine reconcile with the report. The food counter sees every change live but doesn't edit or cancel.

What each status allows

Edits and cancels stay with the cash counter because that's where the money is. If the kitchen runs out of something, they tell the cash counter, which cancels or edits with reason Out of stock. Any till can change any open order; the order keeps its number, till and place in the queue.

Flow

1 · Find it
Header button "Open orders 4". Today's New, Preparing and Ready orders from all tills, newest first, search by number or name.
2a · Edit
The order loads into the order panel with an amber "Editing A-041" bar. Change items, name or Cash/Card. Save shows the payment difference.
2b · Cancel
Confirm dialog with a one-tap reason (Placed by mistake, Customer changed mind, Out of stock, Not collected, Other) and the refund amount.
3 · Food counter
Changes appear live. A changed Preparing order needs Got it before Ready; a cancelled Preparing or Ready order shows red until Remove.

Safety rules

  • Save and Cancel run in a Firestore transaction that re-reads the status first. If the food counter moved it on meanwhile: "A-041 is now Ready, so it can't be edited. Cancel it or start a new order."
  • Edit and Cancel need a connection (transactions don't queue offline). Offline, the buttons are disabled with "Needs a connection"; new orders still queue as today.
  • An edit must leave at least one item. Removing everything offers Cancel instead.
  • Leaving edit mode (Discard, Sign out, switching screens) asks first, like the unsent-order confirm.
  • Reports use the order as it is now. Cancelled stays excluded. Orders detail shows the change history.
